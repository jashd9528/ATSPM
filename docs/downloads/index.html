Tunnel 使用方案一 · Cloudflare Tunnel

  • 按下方官方指南创建 Cloudflare Tunnel。
  • 将隧道连接到 ATSPM 的 MCP 地址，设置 HTTPS 域名。
  • 在 ATSPM“设置 → 隧道”点击“配置”保存 Cloudflare Token，再启动服务。
↗ Cloudflare Tunnel

Tunnel 使用方案二 · OpenAI Secure MCP Tunnel

  • 在 OpenAI Platform 创建隧道并关联 ChatGPT 工作区。
  • 在 ATSPM“设置 → Tunnel”安装客户端，填入 Tunnel ID 和运行密钥。
  • 启动隧道，详细步骤参考下方官方指南。
↗ 官方接入指南

开启开发者模式（Developer mode）

  • 在 ChatGPT 打开「设置 → 安全与登录（Security and login）」，启用 Developer mode。
↗ OpenAI Plugins 官方快速入门

添加 ATSPM MCP 插件

  • 在 ChatGPT 开发者模式中添加 MCP 连接。
  • 方案一填写 Cloudflare 的 HTTPS MCP 地址；方案二选择 Tunnel 及对应隧道。
  • 完成 ATSPM 授权。

安装并测试插件

  • 在新 ChatGPT 对话中选择 ATSPM。
  • 请它读取指定文件或文件夹，核对结果及 ATSPM 历史。
